✈️ Indian Airlines Analytics Dashboard

An interactive Indian Airlines Analytics Dashboard built using Microsoft Power BI to analyze airline performance, passenger traffic, customer ratings, operational efficiency, environmental impact, and estimated profitability.

The dashboard provides a visual overview of India's major airlines, helping users explore performance indicators and compare airlines through an intuitive interface.

📊 Dashboard Preview

!Indian Airlines Analytics Dashboard

🎯 Project Objectives

The main objective of this project is to transform airline-related data into meaningful business insights through interactive data visualization.

This dashboard aims to:

Compare the performance of different Indian airlines.
Analyze passenger traffic and capacity.
Understand monthly passenger trends.
Compare customer ratings across airlines.
Explore fuel efficiency and CO₂ emissions.
Analyze estimated airline profitability.
Present key performance indicators in a single dashboard.
📌 Dashboard Features
1. Airline Selection

Explore airline-specific information for:

Air India
IndiGo
Akasa Air
SpiceJet
Star Air
2. Key Performance Indicators (KPIs)

The dashboard displays important airline metrics, including:

Total Passengers
Passenger Capacity
CO₂ Per Passenger (kg)
Fuel Efficiency
Average Flight Duration
3. Airline Ratings

A comparative visualization showing average customer ratings across different airlines.

4. Monthly Passenger Trend

A line chart representing monthly passenger traffic to identify trends and changes throughout the year.

5. Passengers by Airline

A comparison of passenger volumes across the selected airlines.

6. Estimated Profit by Airline

A donut chart visualizing the estimated profitability distribution across different airlines.
